Napojení na SharePoint přes Power Automate

Krok 1 — SharePoint list
Na svém SharePoint site vytvoř nový List s těmito sloupci:
Role, Rating_Efficiency, Rating_Data, Rating_Comms, Rating_Systems, Friction, Timewaste, Blind, Case_What, Case_Impact, Case_Why, Priority_Order, Priority_Other, Change, Keep, Must_Discuss, Submitted_At

Krok 2 — Power Automate flow
1. Přejdi na make.powerautomate.com
2. Nový flow → Instant cloud flow → trigger: When an HTTP request is received
3. Zkopíruj vygenerovanou HTTP POST URL
4. Přidej akci: SharePoint → Create item → vyber svůj site a list
5. Namapuj JSON pole na sloupce listu
6. Ulož flow → zkopíruj URL

Krok 3 — Vlož URL do formuláře
Otevři soubor HTML, najdi řádek const WEBHOOK_URL = '' a vlož tam svoji Power Automate URL.

⚠️ Power Automate URL obsahuje autentizační token — nikomu ji nesdílej veřejně. HTML soubor by měl být dostupný pouze interně (SharePoint stránka, Teams tab).
